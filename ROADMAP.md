# NDARA Roadmap
## Phase 1: MVP (Terminé)
- Authentification
- Catalogue de cours
- Tableau de bord Étudiant
- Tableau de bord Formateur

## Phase 2: Core Features (Terminé)
- Module de paiement et portefeuille virtuel
- Module d'affiliation
- Support et Modération
- Panel d'administration complet

## Phase 3: Infrastructure & Production (Terminé)
- Optimisation Firestore et requêtes
- Lazy loading et Code splitting pour React (Optimisation des performances)
- Sécurité renforcée (Règles Firestore et Storage validées et durcies)
- Mise en cache avancée (Firebase persistentLocalCache activé)
- Indexation composite (Index générés)
- Cloud functions / Cron jobs (nettoyage, statistiques, rapports, certificats, notifications)
- Monitoring (Audit logs, tracking d'erreurs via middleware)

## Phase 4: Scaling & Mobile (À venir)
- Application mobile native (React Native)
- Internationalisation (i18n)
- Streaming vidéo optimisé (HLS/DASH)
